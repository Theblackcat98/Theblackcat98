### [ASCII-Everything](https://github.com/Theblackcat98/ASCII-Everything)

### [Awesome-AI-Python-Scripts](https://github.com/Theblackcat98/Awesome-AI-Python-Scripts)
A curated collection of OpenWebUI Functions and Plugins that extend Large Language Models (LLMs) within the OpenWebUI environment. Includes AI-powered utility scripts for automation and enhanced user interaction. Expanding to more community-driven tools.

### [Text-Adventure-TUI](https://github.com/Theblackcat98/Text-Adventure-TUI)
A terminal-based text adventure game engine powered by LLM integration (Ollama). Features dynamic narrative generation, event-driven branching, rich terminal UI with the `rich` library, and a persistent save/load system.
